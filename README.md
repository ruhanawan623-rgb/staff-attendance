# Staff Attendance Management System

A web application designed for comprehensive staff and faculty attendance monitoring, leave approvals, department analytics, and campus operations.

🌐 **Live Demo**: [https://ruhanawan623-rgb.github.io/staff-attendance/](https://ruhanawan623-rgb.github.io/staff-attendance/)  
📦 **Repository**: [https://github.com/ruhanawan623-rgb/staff-attendance](https://github.com/ruhanawan623-rgb/staff-attendance)

---

## 🌟 Key Features

### 1. Executive Staff Attendance Dashboard
- **Fluid & Screen-Fitted Architecture**: Expands across all desktop, laptop, and mobile screens.
- **8-Card Balanced KPI Grid**: Total Faculty & Staff, Present Today, Absent, On Leave, Punctuality / Late arrivals, Departments Covered, Student Reference, and Overall Campus Health.
- **7-Day Attendance & Punctuality Trends**: Interactive Chart.js line graph tracking presence and punctuality over the last 7 days.
- **Department Staffing & Attendance Progress**: Live progress meters for every academic and administrative department.
- **Live Faculty Presence Board**: Real-time roster with check-in timestamps, status badges, and quick status actions.
- **Multi-View Tab Switcher**: Switch effortlessly between **Faculty & Staff (Primary)**, **Student Attendance**, and **Unified Campus Summary**.

### 2. Authentication System (Login & Sign Up)
- **Role-Based Authentication**: Supports **Administrator**, **Faculty / Teacher**, and **Staff Member** accounts.
- **Quick Demo Access**: 1-click credentials prefill for immediate evaluation.
- **Password Visibility Toggles**: Interactive Show/Hide password toggles for improved user convenience.
- **Automatic Directory Synchronization**: When a new user signs up as Staff or Faculty, their account is automatically created in the Staff Directory and added to today's active attendance roster.

### 3. Attendance Hub
- **Staff Attendance Marker**: Mark daily presence with quick bulk buttons (*Mark All Present*, *Mark All Absent*), department filtering, and status counters.
- **Student Attendance Marker**: Track student body attendance across grades and sections.
- **Interactive Calendar**: Monthly view with status badges and daily records inspection.

### 4. Records & Leave Management
- **Faculty & Staff Directory**: Manage staff records, contact info, designations, and departments.
- **Student Directory**: Student profiles, roll numbers, guardian info, and attendance rates.
- **Leave Management**: Apply for leaves with reason and date ranges; 1-click **Approve** / **Reject** workflow.

### 5. Analytics & Export
- **Customizable Attendance Reports**: Daily presence sheets, monthly timesheets, department-wise breakdowns, and low attendance alerts.
- **Printable & PDF Ready**: Clean print styling for paper rosters and administrative reporting.

---

## 🛠️ Technology Stack
- **HTML5 & Vanilla CSS**: Custom responsive design system with dark & light theme modes.
- **Vanilla JavaScript (ES6+)**: Modular view controllers and state management.
- **Chart.js**: Dynamic data visualizations.
- **Lucide Icons**: Modern SVG icon library.
- **LocalStorage API**: Client-side reactive persistence.

---

## 🚀 How to Run Locally

1. Clone this repository:
   ```bash
   git clone https://github.com/ruhanawan623-rgb/staff-attendance.git
   ```
2. Open `index.html` in any modern web browser or serve with a local HTTP server:
   ```bash
   python -m http.server 8000
   ```
3. Navigate to `http://localhost:8000` in your browser.
